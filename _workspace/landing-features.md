# winemine 랜딩 페이지 — 노출 기능 전수 정리

> 현재 `src/app/page.tsx`에 마운트된 8개 섹션 + 글로벌 UI에서 사용자에게 보여지는 모든 기능을 코드 없이 정리한 문서.
> 기준 시점: 2026-05-14 (dev 브랜치).

## 0. 글로벌 / 공통 UI

### 0.1 다국어(i18n)
- **자동 언어 감지**: `Accept-Language` 헤더로 브라우저 언어 판별 → `NEXT_LOCALE` 쿠키(1년)에 저장.
- **지원 언어**: 한국어(기본), 영어.
- 모든 카피는 `src/messages/ko.json` · `en.json` 키 구조로 관리.

### 0.2 Floating CTA (떠 있는 다운로드 버튼)
- 스크롤이 일정 지점을 지나면 화면에 고정으로 노출되는 **"앱 다운받기"** 버튼.
- 클릭 시 Waiting List 모달 오픈 + Google Analytics(GA) 클릭 이벤트 추적.

### 0.3 Waiting List 모달 (사전 신청)
- **타이틀**: "사전 신청 — 이메일 또는 전화번호를 남겨주시면 앱 출시 시 가장 먼저 알려드립니다."
- **입력 방식 탭**: 이메일 / 전화번호 전환.
- **검증**:
  - 이메일: Zod 표준 이메일 형식.
  - 전화번호: 한국 형식 `010-0000-0000` 만 허용.
  - 클라이언트(Zod) + 서버(Server Action) 이중 검증.
- **(선택) 마케팅 알림 수신 동의** 체크박스.
- 제출 → Supabase `waitlist` 테이블 insert.
  - 중복 등록은 성공 처리(`23505` 무시).
  - 신규/중복 등록 시 Slack 채널 알림 발송(서버 환경변수 설정 시).
- 제출 중 로딩 상태("잠시만요...") + 서버 오류 메시지 처리.
- 개인정보 안내 문구 노출.
- **완료 화면**: "신청이 완료되었습니다! 출시되면 가장 먼저 알려드리겠습니다."

### 0.4 OG / SNS 공유
- 동적 OG 이미지(`opengraph-image.tsx`) 자동 생성.
- Twitter 카드 이미지 포함.

### 0.5 Google Analytics
- 측정 ID `G-7V8ZDT0TYX` 자동 주입.
- 주요 CTA(Floating, Store Buttons, Final CTA)에 `trackEvent()` 클릭 이벤트 트리거.

## 2. Wine Discovery Section (초보자 친화 스크롤 스토리텔링)
**역할**: 와인 입문자가 "내 와인지도, 어떻게 시작할까?" 라는 질문을 풀어가는 5단계 스크롤 데모.

- **섹션 라벨**: "Beginner's first map"
- **헤더 질문**: "나만의 와인지도, 어떻게 시작할까요?"
- **Step 1 — 먹어본 와인 스캔**
  - 라벨 사진 한 장으로 자동 인식 데모(`ScanPanel`).
  - "찍기만 하면 나머지는 AI가 알아서."
  - 자동 추출 정보: Château(생산자), 빈티지, 등급, 산지.
- **Step 2 — 비슷한 입문 한 병 추천**
  - 사용자가 마신 산지(예: 보르도 레드)에서 출발해, **비슷한 입문급 와인을 지도 위 마커로 추천**.
  - 1~6만원대 입문용 큐레이션(`recommended-wines.ts` mock 데이터).
  - "당신의 다음 한 병" 카드 노출.
- **인터랙션 가이드**
  - "탭해서 다음으로" / "스크롤 해보세요" hint.
- **Outro 카피** + 다음 섹션(Burgundy)으로의 시각적 전환.

## 3. Burgundy Section (부르고뉴 위계 드릴다운)
**역할**: AI가 자동 분류한 내 와인 컬렉션의 **디테일**을 보여주는 전문가 모드 데모.

- **섹션 라벨**: "AI 자동 분류 - 부르고뉴"
- **헤더**: "부르고뉴 한 병의 디테일까지."

### 3.1 4단계 위계 드릴다운
1. **Overview (개요)** — 부르고뉴 전체 지도, 5개 서브지역 노출.
   - Chablis · Côte de Nuits · Côte de Beaune · Côte Chalonnaise · Mâconnais.
2. **Côte (꼬뜨)** — 꼬뜨별 마을(Village) 군집 노출.
3. **Village (마을)** — 마을 내 그랑 크뤼/1er Cru 클리마 노출.
4. **Cru (등급)** — 해당 등급에서 사용자가 마신 와인 리스트.
   - Grand Cru (GC) · 1er Cru · Village · Régional 4단계.

### 3.2 인터랙티브 지도
- **Dot(와인) 클릭 시 드릴인**: 지도 위 와인 마커를 클릭하면 해당 마을/등급으로 즉시 점프.
- **Department 행정구역명 라벨**: 프랑스 데파르트망 경계와 명칭 표시.
- **Breadcrumb 네비게이션**: 부르고뉴 → 꼬뜨 → 마을 → 등급 경로를 한 줄로 보여주고 클릭 시 상위로 복귀.
- **Zoom & Center**: 단계별로 자동 확대 + 중심 이동.

### 3.3 색 필터 (와인 타입 토글)
- 전체 / 레드 / 화이트 / 로제 4탭.
- 각 탭에 전용 아이콘(WineGlassRed · WineGlassWhite · PinkRose).

### 3.4 도멘/와인 데이터 노출
- **도멘**: DRC, Leroy, Rousseau, Dujac, Lafon, Coche, Roulot, Leflaive, Raveneau, Drouhin, Pierre Gelin, Bonneau, Bouchard, Comte Armand, Ramonet, Hubert Lamy, Dureuil-Janthial, François Lumpp, Faiveley, J.A. Ferret, Merlin, de Villaine 등.
- **그랑 크뤼 클리마(예시)**: Romanée-Conti, La Tâche, Richebourg, Musigny, Chambertin, Clos Saint-Jacques, Clos de la Roche, Clos de Vougeot, Chevalier-Montrachet, Corton-Charlemagne, Bâtard-Montrachet 등.
- **1er Cru 클리마(예시)**: Les Amoureuses, Cros Parantoux, Meursault Perrières/Charmes, Saint-Aubin En Remilly, Pommard Les Rugiens, Beaune Clos des Mouches, Pouilly-Fuissé Les Perrières 등.
- **마을 AOC 특이 케이스**: Marsannay Rosé(부르고뉴 유일 마을명 로제 AOC), Bouzeron Aligoté(부르고뉴 유일 알리고테 마을 AOC).
- 각 와인에 **빈티지 · 생산자 · 마을 · 등급 · 시음 노트 · 평점 · 마신 날짜 · occasion** 표시.

### 3.5 정보 칩
- 마을마다 "그랑 크뤼 보유 여부(GC 칩)" 표시.
- 등급별 컬러 시스템: Grand Cru(딥 와인레드) · 1er Cru(골드) · Village(그레이) · Régional(베이지).

## 4. Tasting Note Section (테이스팅 노트 데모)
**역할**: 와인 전문가들이 손글씨로 채우는 양식을 디지털로 옮긴 인터랙티브 데모.

- **Eyebrow**: "기록, CAPTURE"
- **헤더**: "어떻게 기억에 남기시겠어요?"
- **서브헤드**: "와인 전문가들이 손글씨로 채우는 그 양식, WineMine으로 쉽게."

### 4.1 두 가지 모드 전환
- **입문자용 (Beginner)** — 5분, 어려운 용어 없이.
- **전문가용 (Expert)** — WSET · 카우달리 · 부케 휠까지.

### 4.2 와인 타입 탭
- White / Red / Sparkling / **Blind**(블라인드 테이스팅).

### 4.3 단계별 기록 워크플로우 (전문가 모드)
1. **라벨 인식 (Capture)** — 빈티지, 지역, 아펠라시옹, 품종, 가격 자동 추출.
2. **아로마 — UC Davis Wheel**
   - 12 카테고리 부케 휠(클릭 시 어휘 펼침).
   - 어휘 검색.
   - 어휘 hover 시 임팩트 화합물 정보(플레이그라운드).
3. **미각 (Palate) — WSET 5단계 슬라이더**
   - 당도 · 산도 · 바디 · 알코올 · 타닌 · 타닌 질감/성숙도 · 향 강도 · 풍미 강도 · 피니시 길이.
   - 스파클링: 기포 크기, 기포 지속성, 무쎄 질감, 압력(bar), 제조 방식, 도사주.
4. **피니시 — Caudalie 측정기**
   - "Tap to start / Tap to stop"으로 마지막 모금 후 풍미 잔존 시간 측정(1초 = 1 카우달리).
   - 측정 없이 분류만 선택하는 수동 토글.
5. **결함 점검 — Fault Check**
   - 11종 결함 카탈로그 체크리스트.
   - 명시적 사용자 체크가 있을 때만 기록.
6. **오프닝 타임라인 (Opening Timeline)**
   - 코르크를 딴 시점(지금/직접 입력) + 디캔터 사용 여부.
   - 여러 시점(T0, T1...)별로 향 강도/타닌 부드러움/바디 변화 기록.
   - 환원취(Reduction) 감지 + 툴팁 설명.
   - 시점별 새로 등장한 향, 전반 점수, 메모.
   - "이 시점이 정점" 표시.
   - **권장 디캔팅 비교**: 평균 Peak 분과 비교해 "권장보다 빠르게/정확히/늦게 깨움" 5단계 피드백.
7. **평가 (Rating)**
   - 별점, "다시 사시겠어요?" 의향.
8. **블라인드 (Blind)** — `GUESS THE WINE`
   - 품종 · 지역 · 국가 · 빈티지 · 가격대 추정.
   - "정답 공개 (Reveal & Score)" → 총점/100 + 등급(Master Sommelier / Advanced / Enthusiast / Exploring / Finding).

### 4.4 입문자 모드 단계 (Beginner)
- **어떤 와인인가요? → 첫 모금, 어땠어요? (마음에 쏙 / 괜찮았어요 / 음… 별로) → 맛은? → 향은? → 여운은? → 평가 → 오늘의 한 줄**
- 맛 슬라이더(단맛/신맛/무게감/떫은맛/기포)에 일상어 라벨: "안 달아요 ↔ 달콤해요", "물처럼 가벼워요 ↔ 우유처럼 묵직해요" 등.
- 아로마 카드(베리/시트러스/사과·복숭아/꽃/향신료/달콤한 향/흙·나무/빵·견과) — 다중 선택.
- 여운 옵션: 금방 사라져요 / 잠시 머물러요 / 한참 남아요.
- **전문가 용어 학습 팁**: "와인 전문가들은 이걸 이렇게 부른답니다" — 잔당, 산도, 바디, 타닌, 카우달리 용어 풀이.
- "더 자세히 기록하고 싶다면 '전문가용'으로 전환하세요" 안내.

### 4.5 Auto Description (자동 시음 노트)
- 슬라이더 값들로부터 자동으로 시음 노트 한 문단 생성.
  - 화이트/레드/스파클링 각 템플릿 (빈티지·지역·생산자 변수 치환).
- "앱에서 테이스팅 노트 직접 작성하기" CTA.

### 4.6 Mockup 패널
- 종이 시음노트 양식 풍의 미리보기(헤더 "WHITE/RED/CHAMPAGNE/BLIND TASTING NOTES").
- 섹션: 와인, 아로마(시트러스/핵과/트로피컬/꽃/미네랄/발효·오크/붉은 베리/검은 베리/향신료/흙·가죽/오크/자가분해/견과/흙), 미각, 기포·무쎄, 시각(가넷·짙음/투명도/점도), 피니시, 종합 인상, 평가.
- 추정 vs 정답 비교 표(블라인드).

### 4.7 Playground 페이지 (`/tasting-note-playground`)
- 별도 페이지에서 모든 컴포넌트를 직접 만져볼 수 있는 데모.
- "이 페이지의 입력은 어디에도 저장되지 않습니다."
- 하단에 "나만의 기록으로 남기고 싶다면 — 웨이팅 리스트 등록" 다운로드 CTA.

### 4.8 Invite 카드
- 부케 휠 12 카테고리 / 카우달리 측정기 / 결함 11종 체크리스트 / 오프닝 타임라인 — 4개 bullet으로 핵심 소개.
- "Playground 열어보기" CTA(새 탭).

## 요약: 사용자에게 보여지는 핵심 가치 제안

1. **라벨 한 장으로 자동 인식** — Château, 빈티지, 등급, 산지까지 AI가 추출.
2. **세계지도가 와인으로 물든다** — 마실수록 지도가 채워지는 비주얼 메타포.
3. **부르고뉴 한 병의 디테일까지** — 꼬뜨 → 마을 → 등급 → 와인 4단계 위계 분류.
4. **두 가지 깊이의 기록** — 입문자 5분 모드 ↔ 전문가용 WSET · 카우달리 · 부케 휠 · 결함 · 오프닝 타임라인.
5. **취향 큐레이션** — 마신 산지 기반으로 입문급 다음 한 병 추천.
6. **Recap 공유** — 누적 기록을 SNS용 이미지로 자동 생성.
7. **다국어** — 한국어/영어 자동 전환.
8. **사전 신청 (Waiting List)** — 이메일/전화번호 + 마케팅 동의, Supabase + Slack 알림 연동.
